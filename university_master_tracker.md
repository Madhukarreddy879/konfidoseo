## 📌 Standard 8-Point University Profile Template

Every university profile must have the following verified data points:

| # | Data Dimension | Details Required |
|---|---|---|
| **1** | **Identity & Campus** | Official Name, Short/Brand Name, Slug (`/colleges/[slug]`), Campus Address, Nearest Metro/Airport, Established Year, Type (Deemed / State Private / Autonomous). |
| **2** | **Accreditation & Ranking** | NIRF Engineering Rank (2024/2023), NAAC Grade (A++, A+, A), NBA Accredited Branches, AICTE/UGC Approval Status. |
| **3** | **Degree Programs & Seats** | B.Tech Branches (CSE Core, AI & ML, Data Science, Cyber Security, ECE, EEE, Mech, Biotech), Total Intake, Lateral Entry seats. |
| **4** | **Fee Structure Matrix** | Category-A / Convenor Quota Fee, Category-B / Management Quota Fee, NRI Quota Fee, One-time Admission Fee, Hostel + Mess Fee (AC / Non-AC). |
| **5** | **Admissions & Cutoffs** | Entrance Exams Accepted (TS EAMCET / AP EAPCET / KCET / COMEDK / JEE Main / Univ Entrance), Opening & Closing Ranks for CSE/ECE, Direct Admission 12th Board PCM % eligibility. |
| **6** | **Placement Audits** | Average CTC (LPA), Highest CTC (Domestic & International), Placement Percentage, Top 10 Recruiters (Amazon, Microsoft, TCS, Infosys, etc.). |
| **7** | **Direct / Spot Admission Route** | Application window, required documentation checklist, seat blocking timeline, management quota contact protocol. |
| **8** | **SEO & Rich Schema** | Target Primary Keywords (3-5), Meta Title, Meta Description, 5+ high-intent FAQs with JSON-LD Schema markup. |
